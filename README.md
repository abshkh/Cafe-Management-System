# Cafe-Management-System
In this project, we have created a Cafe Management System to help manage the operations of a cafe. The system allows an admin to log in using a graphical login screen. Once logged in, the menu of the café is displayed, showing all available items and their prices. The user is given options to add new items to the menu, update existing items, or remove items that are no longer available. Customers' orders can also be taken through the system by selecting items and specifying quantities. The total bill is then calculated and displayed.
The program also includes features for calculating bills and generating reports, ensuring smooth and efficient management of the cafe's daily operations. It combines both graphical and console-based interfaces for a simple and user-friendly experience.
